# Отпуск в Калининграде, 19–29 ноября 2026

Сайт-планировщик: план по дням, маршруты на карте, прогноз погоды, список вещей на каждый день, рестораны с отметками и оценками, чек-лист броней и бюджет.

Статический сайт без сборки: достаточно открыть `index.html` или включить GitHub Pages
(Settings → Pages → Deploy from a branch → нужная ветка, папка `/ (root)`).

- `data.js` — все данные поездки: дни, точки, вещи, рестораны, бюджет. Править план нужно здесь.
- `app.js` — логика, `styles.css` — оформление, `vendor/leaflet` — библиотека карты.
- Погода: Open-Meteo (без ключа, прогноз на 16 дней). Карта: OpenStreetMap. Маршруты: ссылки и виджет Яндекс Карт, линия на карте — OSRM.
- Отметки хранятся в `localStorage` браузера; перенос между устройствами — кнопки внизу страницы.
